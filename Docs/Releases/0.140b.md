# Stream64 0.140b

Remote mouse control and new tools for Commodore C64 Ultimate firmware 1.2.1.

## Mouse and extra fire buttons

- Enable Mouse Input beside the keyboard and joystick controls. Requires detected official C64 Ultimate firmware 1.2.1 or newer and a mouse-capable input endpoint.
- Move, drag, click with three buttons, and scroll using the C64's port-1 mouse. Escape disables capture; Option-right-click opens Stream64's menu. Focus loss and disconnect release input.
- Configure fire2/fire3 keyboard bindings and gamepad face buttons for port 2.
- For GEOS, select **geos → select input → COMM 1351** and confirm OK. The joystick driver can accept clicks while ignoring mouse movement.

## Device and disk tools

- Device Controls adds tabs for hardware audio mixing, mouse configuration, Software IEC diagnostics, and power/wake settings. Runtime changes verify by readback; Save to Flash remains explicit.
- Drive Bay shows Software IEC state, partitions, and errors, with drive reset, upload write modes, and DNP creation with selectable track counts.
- Commander protects mounted images and their containing folders from mutation, with fresh checks before transfer promotion and moved-source deletion.
- Offline Wake uses the remembered Wi-Fi MAC and starts reconnection. Standby wake requires associated Wi-Fi; Ethernet cannot wake the C64.

## Titles and firmware actions

- Load validated P00 files from drops, Commander, and archives, and display their embedded C64 names.
- Edit or capture companion CFG settings, apply them at launch, and optionally copy or move them with a title. Profiles validate before applying and restore earlier settings on failure.
- Firmware Menu shortcuts handle tape start/pause/resume/stop, cartridge save, and debug-log export. Enter save filenames in the firmware dialog and retrieve files using Commander.

## Compatibility and validation

- macOS 14 or newer; separate Apple Silicon and Intel packages.
- Retains the CRT, Wi-Fi buffering, diagnostics, and reliability improvements from 0.137b–0.139b.
- Validation: 316 regression tests, 13 skipped, zero failures. All three opt-in live C64 Ultimate 1.2.1 acceptance tests passed during development; native UI workflows and manual GEOS pointer movement were also verified.
- Actual standby wake remains unverified on the Ethernet-only test machine. Magic-packet format and UDP delivery were tested.

Choose the ZIP or DMG matching your Mac. Both formats contain the same Developer ID signed, notarized app. SHA-256 files are provided for each architecture.
